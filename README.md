# Клуб Друзей Школы-студии МХАТ — Нетворкинг-игра

Статический одностраничный фронтенд на vanilla HTML/CSS/JS.

## Запуск локально

1. Убедитесь, что файл логотипа доступен по пути `/mnt/data/Лого шс фцк.svg`.
2. Откройте `index.html` в браузере.
3. Игра сохраняет состояние карточки и seed в `localStorage`.

## Структура

- `index.html` — разметка страницы и модального окна.
- `styles.css` — стили, адаптив и анимации.
- `script.js` — логика бинго, localStorage, подсчёт линий.
