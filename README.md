# Нетворкинг игра - Школы-студия МХАТ

Статический фронтенд-проект с интерактивным полем нетворкинг-бинго.

## Локальный запуск

1. Откройте файл `index.html` в любом современном браузере.
2. Нажмите «Начать игру», затем заполняйте карточки именами участников.
3. Для сброса прогресса используйте кнопку «Начать заново».

## Публикация (получить собственную ссылку)

Проект уже подготовлен к деплою на **GitHub Pages** через workflow `.github/workflows/deploy-pages.yml`.

1. Запушьте ветку в ваш GitHub-репозиторий.
2. В GitHub откройте: **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source = GitHub Actions**.
4. Перейдите во вкладку **Actions** и дождитесь успешного выполнения workflow **Deploy static site to GitHub Pages**.
5. После завершения появится публичная ссылка вида:
   - `https://<ваш-логин>.github.io/<имя-репозитория>/`

Если у вас пользовательский репозиторий вида `<ваш-логин>.github.io`, ссылка будет без суффикса репозитория.
