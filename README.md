# Нетворкинг игра - Школы-студия МХАТ

Статический фронтенд-проект с интерактивным полем нетворкинг-бинго.

## Запуск

1. Откройте файл `index.html` в любом современном браузере.
2. Нажмите «Начать игру», затем заполняйте карточки именами участников.
3. Для сброса прогресса используйте кнопку «Начать заново».
